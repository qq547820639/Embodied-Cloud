# 产品范围：先做“可运行实验”，不是通用机器人云

## v0.1 必须成立的用户承诺

1. 用户不用本地安装 CUDA / Isaac Lab。
2. 用户选择一个模板即可得到隔离工作区。
3. 工作区里能看到模板对应的准确运行命令。
4. GPU 模式下，浏览器 IDE 与训练/仿真位于同一容器，代码修改后直接执行。
5. Streaming 模板由**用户启动的 Isaac Lab 进程本身**提供 WebRTC；v0.1 固定使用 49100/TCP + 47998/UDP，并限制同一宿主同时 1 个 streaming workspace。
6. 所有 NVIDIA streaming 端点默认只按可信内网设计；公网必须额外加认证、TLS 与防火墙。

## 明确不做

- 任意机器人“一键真机部署”。
- 自研物理仿真内核。
- 资产交易市场。
- 大而全课程平台。
- 第一版 GPU 切片/超售；策略为一个运行工作区独占一张 GPU。
- 在尚未有真实 GPU 验收前承诺“5 秒冷启动”。

## MVP 成败指标

- 100 注册（外部用户系统接入后统计）
- 30 个真实启动 Workspace
- 15 个完成一个实验
- 5–10 个付费用户/付费实验室意向

## 产品 Gate

只要“30 个真实启动 -> 15 个成功实验 -> 5 个付费/强付费意向”不能成立，停止扩张 Phase 2，不做硬件套件和资产市场。
